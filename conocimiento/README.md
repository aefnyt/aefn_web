# 📚 Documentos del chatbot

Pon aquí los documentos con los que quieres "entrenar" al asistente de la AEFN.

**Formatos aceptados:** `.pdf`, `.docx` (Word), `.md`, `.txt`, `.json`

Puedes crear subcarpetas (por ejemplo `reglamentos/`, `faq/`, `mallas/`).

Cada vez que subes un archivo aquí y haces commit, Vercel vuelve a desplegar el sitio
y el chatbot aprende el contenido nuevo automáticamente (1–2 minutos).

> ⚠️ Todo lo que pongas aquí puede ser respondido a cualquier visitante.
> No subas datos privados (cédulas, notas, teléfonos personales, contraseñas).

Consejos:
- Los PDF escaneados (fotos de papel) **no** tienen texto; pásalos por OCR o cópialos a un `.txt`.
- Un archivo de preguntas frecuentes (`faq.md`) con pares pregunta/respuesta funciona muy bien.
- Los datos que editas desde `/admin` (profesores, eventos, clubes, noticias…) ya se incluyen solos.
